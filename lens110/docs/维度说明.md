| 9 | right_knee |

### 2.2 关节速度 dq `[13:26]`

顺序与 q 完全一致（13 维：左腿 6 + 右腿 6 + 腰）。

### 2.3 上一动作 prev `[26:39]`

顺序与 q 一致（13 维）。来源：`env.action_manager.action`（13 维动作，本身就是 CSV 顺序，无需重排）。

### 2.4 角速度 `[39:42]`

| 索引 | 内容 |
|---|---|
| 39 | ωx |
| 40 | ωy |
| 41 | ωz |

### 2.5 姿态 `[42:45]`（body 系重力）

来源：机器人 base 四元数把世界系重力转到 body 系（`quat_apply_inverse`），实机 IMU 同款。

| 索引 | 内容 |
|---|---|
| 42 | gravity_b x（body 系重力 x） |
| 43 | gravity_b y |
| 44 | gravity_b z |

> 站直时 ≈ [0, 0, -1]。含 roll/pitch 信息，不含 yaw。

|---|---|
| [63:69] | k |

## 4. 动作（13 维）

策略输出 13 维，CSV 顺序（12 腿 + 1 腰），经 `OfficialDanceJointAction` 下发：

```
q_des[腿 12] = action[0:12] × 0.25 + default（腿）
q_des[腰 1]  = action[12] × 0.25
q_des[手臂 8] = MotionCommand 参考关节角（开环，不经策略）
```

手臂 8 关节（left/right shoulder_pitch/roll/yaw、left/right elbow）由参考数据直接给定，策略不控制。

## 5. 与官方 infer_zero 结构的关系

| 项 | 官方（infer_zero） | 本项目官方模式 |
|---|---|---|
| state 单帧 | 45（13q + 13dq + 13prev + 3ω + 3att） | 同（已对齐） |
| state 历史 | 15 帧 | 15 帧（官方版）/ 1 帧（当前无历史实验版） |
| future | 96（3 帧 × (21 关节 + 11 root)，k/k+10/k+20） | 81（精简：21 关节 + 6 root） |
| 观测输入 | 771 | 771 / 126 |
| 动作输出 | 13（12 腿 + 1 腰） | 同（已对齐） |
| 手臂 | 开环参考（csv 第 13~20 列） | 开环参考（MotionCommand） |

当前无历史版（126 维）**不是官方结构**（无历史 + future 精简），仅用于实验；若需导出 ONNX 跑官方 SDK，必须用 history=15、future=96 的 771 版。
